Instalação pelo terminal

Debian / Ubuntu 
sudo apt install ./Pulsares-Explorer-Linux-x64.deb
Fedora / RHEL / openSUSE 
sudo dnf install ./Pulsares-Explorer-Linux-x64.rpm
Flatpak 
flatpak install --user ./Pulsares-Explorer-Linux-x64.flatpak
Snap 
sudo snap install --dangerous ./Pulsares-Explorer-Linux-x64.snap
Arch Linux (AUR) 
mv PKGBUILD-pulsares-explorer-bin PKGBUILD && makepkg -si
Windows (silencioso) 
msiexec /i Pulsares-Explorer-Windows-x64.msi /qn
